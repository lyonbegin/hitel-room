# IXIO APK 원본 업로드 위치

다음 두 원본 파일을 이 폴더에 올려주십시오. 파일 이름은 아래 원본 이름 그대로 사용하셔도 됩니다.

- 익시오_01.33.01.xapk (99,164,559 bytes)
- 익시오 통화녹음_02.02.00.apk (30,313,857 bytes)

런타임 분석 워크플로는 업로드 파일의 SHA-256을 대조하고 일치하는 원본만 사용합니다.
GitHub 웹 브라우저는 개별 파일 25MiB까지 업로드할 수 있으므로 위 파일은 웹 업로드가 되지 않을 수 있습니다. 이때 GitHub Releases의 업로드 화면을 이용하십시오.
