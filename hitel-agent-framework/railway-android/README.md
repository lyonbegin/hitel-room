# Bounded persistent Android host probe
This is an isolated, one-shot Railway runtime capability test, not an authenticated device server. It uses an attached private /data volume for AVD and Android user data, automatically selects emulator acceleration or TCG, checks Google Play, writes or verifies a device marker, and stops. Deploy with no public domain, no account secrets, and restart policy NEVER. A second execution can independently verify persistence across container deployments. Do not send account credentials or expose ADB until the platform has been verified and an authenticated control channel is implemented. A persistent volume may incur storage cost; the probe is intentionally bounded and does not leave an emulator running.
