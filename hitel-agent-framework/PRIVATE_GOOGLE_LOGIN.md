# Google Play account test: GitHub Actions only

All development and emulator tests must use GitHub-hosted Actions on the approved branch. No Railway, paid infrastructure, or external/self-hosted runners. Use the existing Google test account repository secrets only in the native sign-in step. Do not publish screenshots, account identifiers, credentials, or authenticated emulator data. GitHub-hosted runners are disposable; account state may be reused within the same job only. Do not upload authenticated userdata or snapshots. Run login, native app exploration, and subsequent verification in the same job if authentication succeeds. Stop on MFA, CAPTCHA, consent, unknown activity, or sign-in refusal; no bypass. Use the repository's existing free Actions allowance, not additional paid capacity.
