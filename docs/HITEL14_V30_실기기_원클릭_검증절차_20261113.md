# HITEL14 V30 실기기 원클릭 통화 STT 시험 및 단계별 판정

## 확인된 배포물

- 실기기용: [HITEL14_V30_Parallel_ReadyGate_3STT.apk](../downloads/HITEL14_V30_Parallel_ReadyGate_3STT.apk)
- 앱 ID: `app.hitel.callflowlab.v30.onetap` (원본 V22와 **다른 앱**으로 병렬 설치)
- 버전 코드: `38`, ABI: `arm64-v8a`
- SHA-256: `3649aed99ff313f436e75ebd8936cb27c436ac3262b0d7da80ec16ea746d5855`
- 원본 V14 마이크 STT, V22 출력음 STT, V23 직접 PCM STT, M4A AAC follower, MediaCodec, PCM 미디어 AudioTrack 및 기존 로그 저장 코드는 재구현하지 않고 유지합니다.

## 버튼 하나로 시작하는 절차

1. 삼성 전화 앱의 **통화 자동 녹음**을 미리 활성화하고 실제 통화녹음 `M4A` 저장 위치를 확인합니다. 해당 기능은 기종·지역·전화 앱 설정에 따라 다릅니다.
2. 기존 HITEL14 V22를 삭제하지 않고 V30을 설치하고 실행합니다.
3. 상단 **▶ 테스트 시작 · 기본 전화 앱 자동 열기**를 **한 번** 누릅니다.
4. 최초 설정 시 Android 폴더 선택기가 나타나면 삼성 통화 녹음 폴더를 선택하고 읽기 접근을 허용합니다. Android가 전화 상태·오디오 권한을 요청하면 허용합니다.
5. Android 시스템 화면 공유/녹화 동의창에서 **전체 화면**을 선택하고 시스템의 시작/허용 버튼을 누릅니다. 이 동의는 앱이 자동으로 건너뛸 수 없으며 매 새로운 MediaProjection 세션마다 필요합니다.
6. V30은 원본 한국어 모델을 확인·로딩한 후 **AudioRecord.RECORDSTATE_RECORDING**이 실제 시작되었는지 확인합니다. 동시에 **CallStateGate** 및 M4A 폴더 감시 서비스 준비 신호를 확인합니다.
7. **두 준비 신호가 모두 확인된 경우에만** 기본 전화 앱을 자동으로 엽니다. 번호 입력과 발신은 사용자께서 실행하시면 됩니다.
8. 통화 중에는 M4A 새 파일 생성과 **3회 연속 실제 크기 증가**를 검증하여 원본 AAC→16kHz PCM→`USAGE_MEDIA` AudioTrack→사용자가 허용한 MediaProjection 출력음→Sherpa STT를 연결합니다.
9. 통화 종료 `IDLE` 후 V30 화면 맨 위 **📁 로그 저장 · 폴더 선택**을 누르면 기존 방식으로 `HITEL14_latest_log.txt`를 최신 로그로 덮어쓰고 파일 읽기 검증을 수행합니다.

## 준비 상태를 성공으로 오인하지 않기 위한 필수 이벤트

| 단계 | 필수 로그 | 실패 시 의심 지점 |
|---|---|---|
| 시작 버튼 터치 | `ONE_TAP_START_REQUEST` | 실제 W03 버튼 이벤트 |
| 저장 폴더 | `ONE_TAP_SAF_READY` | SAF 권한·삼성 통화녹음 폴더 경로 |
| 전화 권한 | `ONE_TAP_PHONE_PERMISSION_GRANTED` 또는 기존 허용 | READ_PHONE_STATE |
| 오디오 권한 | `ONE_TAP_AUDIO_PERMISSION_GRANTED` 또는 기존 허용 | RECORD_AUDIO |
| 캡처 동의 | `ONE_TAP_WAIT_PROJECTION_CONSENT` | Android 시스템 미디어캡처 허가 |
| 모델 준비 | `ONE_TAP_WAIT_MODEL_READY` | 한국어 ZIPFORMER 모델 준비·다운로드·로딩 |
| 실제 출력음 캡처 시작 | `ONE_TAP_CAPTURE_AUDIO_RECORDING` | AudioRecord 초기화, MediaProjection |
| 통화 감시 준비 | `ONE_TAP_CALL_MONITOR_ARMED` | CallStateGate 등록, 자동 감시 foreground service |
| 자동 준비 완료 | `ONE_TAP_BOTH_ACTUALLY_READY` | 위 두 서비스가 실제 시작되었는지 |
| 기본 전화 앱 열림 | `ONE_TAP_DIALER_OPENED` | ACTION_DIAL 호출·실패 |
| OFFHOOK | `PIPELINE_OFFHOOK` | 전화 연결 이벤트 수신 |
| 녹음 파일 증가 | `LIVE_M4A_CONFIRMED_GROWING` | 실제 삼성 통화녹음/SAF 사용 가능 여부 |
| PCM 첫 프레임 | `FIRST_16KHZ_PCM_READY`, `PIPELINE_PCM_FIRST` | AAC follower·MediaCodec·샘플 수 |
| 미디어 출력 | `SPEAKER_TRACK_STARTED`, `PLAYBACK_PROGRESS` | USAGE_MEDIA AudioTrack, 출력 라우팅, PCM RMS |
| 실제 캡처 신호 | `SPEAKER_STATUS`의 `출력음 RMS=` 값 | 출력음 캡처·믹싱 정책·오디오 포커스 |
| 한국어 인식 | `SPEAKER_PARTIAL`, `SPEAKER_FINAL` | Sherpa 모델, AudioRecord 입력 |
| 통화 종료 | `PIPELINE_CALL_IDLE`, `SESSION_CLOSED` | IDLE 감지와 워커 정리 |
| 로그 보관 | `MANUAL_LOG_SAVE_VERIFIED` | SAF 저장, 덮어쓰기, 재열기 SHA 검증 |

**중요:** 에뮬레이터 GSM은 전화 상태를 모의할 뿐 상대방의 실제 이동통신 음성을 제공하지 않습니다. PCM 재생 및 음성 인식에 시험 M4A를 사용하더라도 실기기 통화 수신 음성 검증으로 표시하지 않습니다.
