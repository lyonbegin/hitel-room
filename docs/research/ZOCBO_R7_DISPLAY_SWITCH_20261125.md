# R7 original storage with display switch

Restores original R7 source and adds a persistent native Android Switch to the existing diagnostic toolbar. ON displays the original viewer. OFF covers only the viewer's visible content; the original viewer activity and its PDF processing remain active. No PDF storage, authorization, retention, cleanup, cache lookup or network logic is changed. No new file copies or offline access are introduced. This is a display-only switch, not a claim that background PDF rendering stops. Default ON.

No new JavaScript bridge or automated request is introduced. Build and authenticated device validation are separate.
