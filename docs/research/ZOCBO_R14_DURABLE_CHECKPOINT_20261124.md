# 족보닷컴 기출 목록 수집기 R14 — 부분저장·일시정지·이어하기 수정

기준: 2026-11-24, R13 시험 빌드 `2231ab0ccd77c1027ddd07e8b786d30fe1cc4206`에서 분기.

## 사용자가 확정한 범위

- 수집은 기존 Android 앱 **내부**에서 실행. 별도 웹 크롤러/서버 없음.
- 로그인/SSO/기존 WebView 및 PDF 뷰어 경로는 유지.
- 지역은 원본 **왼쪽 시도 → 오른쪽 [지역] 전체** 셀렉터를 사용하고 학교 ID를 임의 생성하지 않음.
- 수집 항목은 시험지 번호와 제목/학교/학년/과목 등 *메타데이터*만 해당. 시험지 PDF는 다운로드하지 않음.
- 수집되는 각 페이지를 SQLite에 즉시 기록하고, Android 저장 대화상자로 CSV/JSON을 내보냄.
- 원본 서버의 접근 제한/오류를 우회하지 않고 오류 발생 시 중단.

## 확인된 R13 문제

R13의 `ReadingCollectorController.Bridge.snapshot`은 `originalAreas.add(found)`로 지역 선택 결과를 **메모리에만 보관**.
실제 첫 페이지 시험번호 저장은 `finishAreaDiscovery`에서 모든 지역 탐색을 마친 뒤에 수행.
따라서 지역 탐색 도중 일시정지/종료 시 앞서 탐색한 지역과 시험번호가 유실될 수 있음.

일반 페이지의 `ReadingCollectorStore.savePage()`는 이미 exam 행과 다음 페이지 체크포인트를 SQLite 트랜잭션으로 묶고 있음.

## R14 변경

1. SQLite 기존 `exams`, `checkpoints` 유지하고 DB v1 → v2 업그레이드로 `area_scopes` 추가.
2. 원본 지역 조회가 완료되는 즉시 유효한 첫 페이지 시험번호를 기존 `savePage()`로 저장. 성공한 지역은 `saveArea()`로 `site/area_index/학교 ID/원본 표시값/첫 페이지` 저장.
3. 중단 후 같은 연도 범위로 재시작 시 `loadAreas()`를 사용해 이미 조회한 지역을 복원하고 `area_index+1`부터 재개.
4. 원본 왼쪽 지역 목록과 저장된 지역 순서가 일치하지 않으면 자동 건너뛰기 대신 정지.
5. 서버 응답 목록이 비어 있지 않은데 유효한 시험번호가 0개이면 페이지 진행 체크포인트를 커밋하지 않고 오류로 중단.
6. 지역 탐색 도중 CSV/JSON 내보내기를 실행하면 탐색 상태를 먼저 정지시키고 그 시점까지 **커밋된 DB 행**만 내보냄.
7. 일시정지 로그에 **SQLite에서 다시 읽은 페이지 위치** 및 실제 DB 건수를 표시.

## 저장 구조

- 데이터: 앱 사설 DB `zocbo_exam_metadata_v1.db` (파일 이름 불변, 스키마 2)
- 시험지: `exams(exam_no PRIMARY KEY,...)`; 중복 번호는 덮어쓰기.
- 순차 페이지 위치: `checkpoints(run_key,...)`; `savePage()` 트랜잭션에서 시험번호와 함께 저장.
- 지역 탐색 위치: `area_scopes(run_key,site,area_index,...)`; 범위 식별자는 `discovery-v2-시작연도-종료연도`.
- 시험번호가 한 건도 관측되지 않은 지역은 지역 선택 정보만 저장할 수 있으며, 0건을 전국 수집 완료로 오인해서는 안 됨.

## 실기기 검증 절차 (미완료)

1. R14 시험 APK를 설치·로그인 후 수집 화면에서 연도 범위 지정.
2. 첫 지역 결과를 확인하자마자 **일시정지**. 상태의 `저장 DB` 건수와 `COLLECTOR_AREA_PERSISTED` 로그 확인.
3. **CSV 파일 내보내기**를 누르고 해당 CSV에 첫 지역 시험번호가 포함됐는지 확인.
4. 앱 완전 종료 → 재실행 → 같은 연도 범위로 **이어하기**. 지역 1번부터 전부 반복하지 않고 저장된 다음 지역부터 시작하는지 확인.
5. 중간 페이지를 수집한 뒤 일시정지·내보내기·재실행하여 `checkpoints`와 파일 행 수가 일치하는지 확인.
6. 앱 데이터 삭제/재설치/DB 스키마 다운그레이드는 **기존 DB 유실 위험**이 있으므로 검증 전 실시하지 않음.

## 검증 경계

- Java 컴파일 및 APK 서명이 완료돼도 **실제 전국 수집 성공**을 의미하지 않음.
- 원본 서버 로그인 상태와 지역 선택기/시험 목록의 실제 응답을 확인해야 함.
- 사용자가 제공한 `zocbo_exam_metadata_20261123_232003.csv` 파일의 본문이 이번 대화 컨텍스트에 없는 상태이므로 이전 CSV의 실제 행 수·시험번호 정합성은 아직 대조하지 못함.
