# R7 official PDF attachment save test
Baseline: 0278f5cad2a5b9fe4463af49fcb051c36113f1f0.
This build does not replace the original native viewer, login, or entitlement/count checks.
On the original previousExam.asp WebView, call window.hitelPdfTitleLink.armOfficialSave("15958886") then use the site's official download function. Check JSON.parse(window.hitelPdfTitleLink.officialSaveStatus()). Only an actual same-service HTTPS attachment PDF callback triggers one Android DownloadManager job. If no attachment callback arrives, status expires with NO_OFFICIAL_PDF_ATTACHMENT. A native viewing operation alone does not trigger saving. Verified PDF header and size are required for successful publication to Download/HITEL-Zocbo/<examId>.pdf. The ID is the user's label, not independently verified against the attachment metadata. Existing original download listeners are retained for unarmed/nonmatching callbacks. No original viewer cache access, API invention, or change to download counts. Authenticated device test remains required. Test signing may require replacing the existing app; preserve login/data before doing so.
