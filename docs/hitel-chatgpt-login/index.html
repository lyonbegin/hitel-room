ChatGPT 두 계정 · 원격 Chrome 로그인

계정 A와 B를 처음 한 번씩 직접 로그인하시면 GitHub Actions가 각각의 Chrome 로그인 프로필을 암호화해 저장합니다. 이 페이지 자체는 GitHub Pages 정적 웹페이지이므로 서버 비용이 발생하지 않습니다.

원격 Chrome noVNC 열기 보호된 접속 권한은 이 페이지의 공개 소스에 저장되지 않습니다. 개인용 링크에서만 확인할 수 있습니다.

원격 Chrome 사용법

① ChatGPT 계정 A 원격 Chrome에서 Google 또는 OpenAI로 로그인하신 뒤 A 로그인 확인·저장을 누르십시오.
② ChatGPT 계정 B A 저장 후 B용 Chrome이 열립니다. 다른 계정으로 로그인하신 뒤 B 로그인 확인·저장을 누르십시오.

HITEL이 비밀번호나 인증번호를 받지 않습니다. 공식 Google·ChatGPT 로그인 창에서 직접 입력하십니다.

원격 Chrome이 실행 중이지 않을 때

GitHub Actions에서 임시 Chrome을 실행할 수 있습니다. GitHub에 로그인된 상태에서 아래 링크의 Run workflow를 선택하십시오. 이 과정은 GitHub Pages의 정적 버튼으로 인증 없이 대신할 수 없습니다.

GitHub Actions에서 Chrome 실행 임시 Chrome은 GitHub Actions 실행이 끝나면 종료됩니다. 링크가 만료된 경우 새로 실행하셔야 합니다.
