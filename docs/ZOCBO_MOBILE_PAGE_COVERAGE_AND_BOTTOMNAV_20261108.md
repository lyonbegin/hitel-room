# 족보닷컴 모바일 원본 연결·미작동 감사 — 2026-11-08

## 결론
**전체 연결 아님.** Playwright로 실제 족보닷컴 모바일 원본 15개 기본 경로, 추가 발견된 원본 메뉴 53개, 총 68개 URL 접속 사례를 검사했습니다. 이는 중복 URL과 리다이렉션을 포함한 사례 수이며, 사이트의 모든 고유 페이지나 로그인 이후 전체 기능을 검증했다는 의미가 아닙니다.

## 추가 원본 메뉴 53개: 중요한 미연결 및 특수동작
- 원본의 실전대비, 최다오답, 부교재, 교과서 변형, 계산력·서술형, 문법·독해, 강남 3구, 수학MASTER, 예비중1·고1, FAQ·고객센터, 결제·이벤트, 스카이탭, 학원·선생님 관련 주소도 발견하여 확인했습니다.
- 53건 모두 최종 HTTP200 응답. 다수 URL은 다른 원본 학습 메뉴로 이동되며, 화면이 실제로 사용 가능한지를 의미하지는 않습니다.
- 결제 /payment/ 는 /Member/login.asp?RtnUrl=/payment/ 로 이동.
- 예비고1·예비중1 시험 경로는 sign.zocbo.com/account/default.asp 로 이동.
- 중간고사 2026 이벤트 /event/pre-test2026c/ 는 로그인 화면으로 이동.
- /Freetrial/main_s.asp 는 원본 모바일 홈으로 이동.
- /freetrial/freereading.asp 는 Apple 앱스토어로 이동하며 웹 내부 기출열람 기능이 아닙니다.
- 일부 메뉴는 이동 직후 1.1초 시점에서 본문 0자로 기록. 이후 비동기 로딩 가능성이 있으므로 완전 장애로 단정하지 않았습니다.

## 하단 문제은행 버튼 변경 및 테스트
- 새 통합형 앱 하단 메뉴의 대상 화면을 안내용 bankHome에서 실제 데이터가 표시되는 bankSearch로 변경.
- 실제 배포 Railway 주소에서 직접 클릭하여 URL 전환, 고1 수학 공개시험지 411건 및 대단원 7개 로딩, 하단 선택 상태 확인.
- 8개 앱 미리보기의 족보닷컴 하단 문제은행에는 종전 예시 문제 4개가 존재했음. 해당 화면은 별도 서비스 수정 브랜치에서 실제 네이티브 문제은행 화면으로 연결 처리.

## 미구현과 테스트 한계
원본 로그인·회원 데이터·이용권·실제 문제 본문/정답/해설·개별 시험지 원본 딥링크·PDF 다운로드·결제·앱 전용 기출열람은 **미구현 또는 미검증**입니다. 원본 사이트가 HTTP200을 응답한다고 기능 완료로 표시하지 않습니다. TinyFish를 사용하지 않았습니다.
