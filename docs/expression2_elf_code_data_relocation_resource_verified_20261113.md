## 결합을 위한 다음 구체적 분석

1. 함수→상수: `ADR/ADRP` 뒤 `ADD/LDR` 레지스터 추적으로 실제 데이터 객체 경계를 확인합니다.
2. 함수→다른 함수: 원본의 직접 호출 그래프와 동적 디스패치, 외부 심벌을 교차 분석합니다.
3. 함수→실행 상태: `.data/.bss/.data.rel.ro` 및 힙 생성 객체의 생성·해제/소유권을 분리합니다.
4. 함수→모델/리소스: `libLiteRt.so` 시그니처 및 IMX 파일 로딩/초기화 경로를 연결합니다.
5. 검증용 SO에서는 확보된 원본 함수의 입출력과 재구현 함수의 결과를 별도로 비교하고, 전체 추론·영상 프레임 동등성은 실제 출력 전까지 미완료로 유지합니다.

**판정:** 원본 SO의 함수뿐 아니라 섹션, 정적 상수, 전역 상태, 재배치, AAR 외부 구성, IMX 리소스의 분류는 원본 바이너리로 직접 검증 완료했습니다. 함수별 데이터 참조를 정확히 잇는 전체 그래프와 독립적인 완성 SDK의 출력 검증은 별도 작업입니다.
