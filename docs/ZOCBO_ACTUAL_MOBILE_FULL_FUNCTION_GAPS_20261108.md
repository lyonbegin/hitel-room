# 족보닷컴 모바일 원본↔HITEL 실제 기능 누락 점검 (2026-11-08)

## 수행 및 증거

- GitHub Actions/Playwright에서 원본 모바일 **15개 URL** + HITEL **12개 화면** 직접 열람: [실행 #42453783822](https://github.com/lyonbegin/hitel-room/actions/runs/42453783822).
- 모바일 원본 홈/메뉴에서 실제 발견한 **36개 고유 경로** 각각 GET 이동, 리디렉션·본문·HTTP 검사: [실행 #42453994924](https://github.com/lyonbegin/hitel-room/actions/runs/42453994924).
- 36개 경로는 모두 최종 HTTP 200. 4개 경로는 목적지 변경 (무료 기출열람실→Apple App Store; 무료 이용권→홈; 예비중1·예비고1 족보→sign.zocbo.com).
- 원본 소스의 36개 경로 중 HITEL 12개 화면의 실제 공식 href 경로로 존재하는 것은 **6개**, 아예 같은 href 경로가 없는 것은 **30개**. href 존재는 기능 구현의 증거가 아님.
- 모든 검사는 익명 공개페이지 GET/단순 읽기·시각화이며 회원 로그인 시도, 결제, 유료 다운로드를 하지 않음. TinyFish 사용 안 함.

### 추가 주요 누락

1. **중등·고등 개념학습**: 실제 모바일 원본은 `menu_cd=000010000100001`(중등), `000020000100001`(고등)에서 동적 계층 목록을 정상 출력함(각각 `#examMain` 텍스트 4,625 / 4,089자). HITEL 별도 학습·계산력 화면 미구현.
2. **실전대비·직전대비**: 원본 모바일 상단 단계 탭에 별도 기능 존재. HITEL은 같은 화면·데이터 흐름 구현 안 됨. 직전대비 일부 외부 링크만 있음.
3. **학교별 맞춤학습**: 원본 실제 중·고 페이지 `M/expected.asp`, `H/expected.asp`에서 지역·구/군·학교·학년·과목·범위 조작 UI가 존재하지만 HITEL은 외부 링크만 표시.
4. **성적 진단평가**: 원본 `Freetrial/learningtest.asp`에서 학년·학기·과목 선택 UI 확인. HITEL은 외부 링크만 표시.
5. **예비중·예비고 콘텐츠, 업로드 일정·현황, 공지, 고객센터, SKYTAB 관련 30개 경로**: HITEL 화면의 공식 href에 일치 경로 누락. 일부 구식 이벤트는 현재도 HTTP 200 응답하지만 최신 유효성을 별도로 판정해야 함.

## 판정 기준

**연결 완료 아님.** 원본 HTTP 200, 원본 링크가 존재, HITEL 시험지 ID 표시, 공개자료 버튼을 누르는 것은 각각 실제 시험지 문항 열람이나 파일 다운로드 완료와 다릅니다. 인증 후 페이지 및 공개되지 않은 숨겨진 원본 전체 URL 개수는 확인하지 못했습니다. 모든 내부 페이지를 검증했다고 주장하지 않습니다.
