## 학교 검색 동작
- 원본의 읽기 전용 `/_api/community.api.asp` 명령 `GET_REGION_LIST` 및 `GET_SCHOOL_LIST`를 실제로 확인해 연결했습니다.
- 서울 지역의 구·군 26개, 서울 강남구 내 학교 25개가 익명 조회됐으며 숙명여자중학교 원본 ID는 `6357`로 확인.
- 학년 및 과목 선택 버튼은 원본 브라우저에서 확인된 선택지로 작동합니다. 원본의 전체 동적 범위 선택·시험지 생성은 공개 상태에서 검증되지 않았습니다.
- 원본 `/ZocboMid/ZocboExam/Exam_Default.asp`는 공개 비로그인 요청에 JSON 목록을 반환하지 않아 학교별 시험지 생성·다운로드를 완료로 표시하지 않습니다.

## 미구현/검증 제외
개별 원본 시험지의 **로그인 후 본문 보기, 실제 PDF·HWP 다운로드, 동영상 재생, 결제**, 학교별 시험범위에 맞춘 실제 시험지 생성, 로그인 세션 공유는 연결하지 않았습니다. 현재 자료번호 선택은 해당 메타데이터 정보창을 여는 기능으로, 원본 시험지 직접 딥링크가 아닙니다. 원본의 모든 학년/과목/교과서 조합이 13개 하위 메뉴 전부에서 동작한다고도 주장하지 않습니다. 학년·과목 실시간 조회가 확인된 범위는 기존 수준별 학습을 중심으로 합니다.

## 개발 파일
- server.mjs: 공개 문제은행·원본 메뉴 데이터·지역/학교 목록 라우트.
- public/zocbo-all-menus.js, .css: 6개 탭, 13개 하위 화면, 실제 ID·학교 옵션.
- public/zocbo-original-data/*.json: GitHub Actions 원본 브라우저의 실제 결과.
- docs/zocbo-original-input/*.html: 사용자가 제공한 실제 모바일 DOM 참고.
- tools/zocbo/test_all_six_menus.py: 실제 선택·개수·ID 360px/390px E2E.

기존 기능의 성공 여부와 각 한계를 구분하여 보고합니다. TinyFish는 사용하지 않았습니다.
