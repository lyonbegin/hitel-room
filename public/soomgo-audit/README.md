# 숨고(Soomgo) 고수찾기 UI 비교

당근·강남언니와 별개로 숨고 실제 사이트의 디자인과 UI를 브라우저로 분석합니다. 원본 페이지는 서울 성동구 이사/입주 청소 고수찾기 결과 화면입니다.

GET / 재현 비교 대시보드, GET /clone 재현 화면, GET /report 측정 결과, GET /artifacts/original.png 및 /artifacts/clone.png 캡처, GET /tools-report Playwright MCP · Chrome DevTools MCP · REA 확인.

동일 해상도 1440×900 비교용, 본 HITEL 프로젝트의 사업 모델과 구분한 UI 연구 페이지입니다.
