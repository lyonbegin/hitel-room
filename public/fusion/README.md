# HITEL 4소스 통합 실험 프런트

- `index.html`: 4소스 통합
- `daangn.html`: 당근 동네업체 지역 검색 흐름의 독립 재구현
- `unni.html`: 강남언니 의료 상품·시술 카드 흐름의 독립 재구현
- `soomgo.html`: 숨고 서비스 분류·견적 질문 흐름의 독립 재구현
- `naver.html`: 네이버 예약 8유형과 업종별 예약 흐름의 독립 재구현
- `categories.json`: 기존 899개 원본 분류(플랫폼별 원출처 보존)

실제 업체·시술 가격·예약상태는 포함하지 않았습니다. 시연 견적과 예약은 브라우저 저장소에만 기록되며 서버에 전송되지 않습니다. 실제 담당자 전화 연결은 사업자가 동의하여 등록한 업무용 번호가 있을 때만 활성화됩니다.

독립 재구현이며 제3자 사이트의 원본 코드나 상표/에셋을 복제하지 않습니다. REA 분석 완료본이 아니라 공개 화면과 제공 분류에 기초한 1차 기능 프런트입니다.
