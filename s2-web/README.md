# HITEL S2 Railway UI preview

This directory serves the 2026-11-09 refined monochrome user interface with home, requests, calendar, AI assistant, My and settings. No search marketplace. The user-facing data is local browser demo data; no real calls, payments or external bookings are submitted.

Railway root directory: `/s2-web`. Start: `npm start`. Health endpoint: `/health`. Android avatar proof-of-concept lives separately in `/android-avatar` on this branch.
