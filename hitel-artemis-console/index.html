ARTEMIS 실행 콘솔

자연어 테스트 → GitHub Actions → HITEL AI → ARTEMIS 계획
개발 환경 · HITEL AI
공개 저장소입니다. 테스트 목표와 실행 기록은 공개될 수 있습니다. 개인정보, 계정, 비밀번호, 실제 고객 업무를 입력하지 마세요.

01 · 업무 요청

테스트 목표를 입력하면 GitHub의 테스트 요청 페이지가 열립니다. 요청을 제출하면 기존 HITEL AI 연결을 통해 ARTEMIS의 텍스트 계획 테스트를 실행합니다.

02 · 실행 상태

대기 중
    GitHub Actions 실행 기록기존 프레임워크 소스
      현재 텍스트 계획 테스트입니다. 실제 AI 응답은 별도 승인된 작업에 한해 실행되며, 기기 동작은 검증 대상이 아닙니다.

      03 · 현재 실행 구성

      ARTEMIS Planner → 동일 저장소의 HITEL Universal AI 전송 어댑터 → 기존 HITEL AI 서버 → 계획 결과 검증. 화면 이미지 및 실제 모바일 실행은 아직 연결하지 않았습니다.
