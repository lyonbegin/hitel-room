새 프로그램은 hitel-api-monitor/services.json에 저장소와 대화방 이름 접두어만 등록하시면 관제 표에 자동으로 추가됩니다. 기존 Railway API 수정이나 재배포는 하지 않습니다. 대화 본문은 조회하지 않으며, API가 공개하는 상태 및 GitHub 워크플로 기록만 집계합니다.
