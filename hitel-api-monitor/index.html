‘진행 중’은 GitHub Actions에서 확인된 실행 상태입니다. ChatGPT가 해당 채팅방에서 실제 답변을 작성 중이라는 의미는 아닙니다. 기존 API는 채팅방 이름과 연결 여부만 공개합니다.

화면은 3초마다 새 상태 파일을 요청하며 GitHub 직접 실행 기록은 약 3분마다 확인합니다. GitHub Pages 상태 파일은 GitHub Actions가 약 5분 간격으로 갱신하므로 실제 작업과 시간차가 있을 수 있습니다. 마지막 수집 시각을 꼭 확인해 주십시오.

이 화면은 읽기 전용입니다. HITEL API, Railway 서버, 실행 중인 채팅 작업에는 명령을 보내지 않습니다.
