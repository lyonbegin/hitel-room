# HITEL Vite UI Flow

모바일 우선 UI 동선 검토용 React/Vite 앱. 기존 HITEL 서버와 통신하지 않습니다.

- 홈의 세로 스크롤 서비스 섹션, 검색·분야·역할 선택·상세·문의·대화·등록·커뮤니티·기관·내 활동
- 기존 기획의 122 화면·상태 + HITEL 신규 69 화면·상태 = 191개 진입 항목
- 데모 데이터만 사용하며 실제 통화·메시지·예약·결제 API 미연결
- `npm install && npm run dev`; 배포 `npm run build && npm run start`

원본 당근 APK에서 독점 소스나 이미지는 포함하지 않았습니다. 디자인 패턴만 참고했습니다.
